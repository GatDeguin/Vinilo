Conectar la búsqueda de YouTube

La búsqueda automática usa YouTube Data API v3. La reproducción por enlace no necesita clave. Google recibe la consulta y los datos necesarios para cargar su reproductor.

Se conserva sólo en esta pestaña. No se exporta ni se incluye en el HTML. Una clave utilizada en el navegador es visible para su usuario: restringila por sitio y por API.

Crear y restringir una clave
  1. Abrí Google Cloud Console y creá un proyecto.
  2. Habilitá YouTube Data API v3.
  3. Creá una clave API. En restricciones de aplicación, elegí sitios web y autorizá https://gatdeguin.github.io/*.
  4. En restricciones de API, permití sólo YouTube Data API v3. Pegá la clave arriba. El cupo depende de tu proyecto.

GitHub Pages requiere alojar el HTML por HTTPS; abrirlo con file:// no proporciona el referente requerido por YouTube.

Fuentes y privacidad

Sin cuentas de Vinilo, rastreadores propios ni descargas de YouTube. Los vídeos se reproducen en un iframe oficial visible; pueden incluir anuncios o estar bloqueados por sus propietarios. Se pausa YouTube al ocultar la pestaña o cuando su pantalla deja de estar visible. No se promete reproducción con la pantalla bloqueada.

El HTML contiene todos los gráficos y el código. YouTube y sus portadas necesitan Internet; el audio local no. Los metadatos de YouTube se descartan a los 30 días sin actualizar; se conserva el identificador elegido por vos.
